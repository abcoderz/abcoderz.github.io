# ApiClient — App Support & Documentation

**ApiClient** is a mobile developer client to test, debug, and manage REST, GraphQL, and WebSocket APIs directly on your mobile device.

---

## 🛠️ Key Features

### 1. REST & GraphQL Client
* Create HTTP & HTTPS requests using Raw body (JSON, Text, JavaScript, HTML, XML) and Form-data.
* GraphQL query and variable editor with syntax formatting.
* Custom headers with auto-completion hints.
* Format and minify JSON responses.
* Copy, save, and share API responses.

### 2. API Collections
* Create collections and save REST/FCM requests.
* Import and export Postman collections (v1, v2.0, v2.1) and OpenAPI / Swagger specs.
* Organize with nested folders.

### 3. Real-Time WebSockets & SSE
* Connect to `ws://` and `wss://` endpoints with live frame logging.
* Live Server-Sent Events (SSE) streaming inspection for LLM/AI APIs.

### 4. Firebase Cloud Messaging (FCM) Tester
* Send FCM push notifications using HTTP v1 with on-device OAuth2 or Bearer tokens.
* Custom notification payloads and topic messaging.

### 5. Code Generator
* Generate ready-to-run code snippets in 9 languages: Swift, Kotlin, Python, JavaScript, Dart/Flutter, Go, PHP, Java, and cURL.
