# Rupee Control — App Support & FAQ

**Rupee Control** is a 100% offline personal expense tracker and Khata ledger for India.

---

## ❓ Frequently Asked Questions

**Where is my data stored?**  
Only on your device, encrypted at rest. There are no accounts, servers, or cloud sync.

**How do I backup and restore my data?**  
Go to **More → Backup & Restore → Create Backup**. Save the file to iCloud Drive, Google Drive, or local storage. You can restore it anytime on a new device.

**Can I transfer backups between Android and iPhone?**  
Yes! The backup file format is compatible across both Android and iOS versions of Rupee Control.

**I purchased Pro but still see ads.**  
Go to **More → Upgrade to Pro → Restore Purchases** (ensure you are logged in with the same Apple ID / Google Account).
